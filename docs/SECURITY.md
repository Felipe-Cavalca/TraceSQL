# Política de segurança

Se você achou uma vulnerabilidade no TraceSQL, **não abra uma issue pública**.

## Como reportar

1. Abra a aba **Security** do repositório no GitHub.
2. Clique em **Report a vulnerability**.
3. Descreva o problema, os passos para reproduzir e a versão afetada.

O relato fica privado. A pessoa que mantém o projeto responde pelo mesmo canal.

## Versões com suporte

Só a última Release recebe correções de segurança.
